Trading Journal

TradeZella tarzında profesyonel trading takip uygulaması

⚠️ Önemli: Uygulamayı başlatmak için önce Node.js yüklü olmalı!

📋 Kullanım Talimatları:

Yöntem 1: start.bat dosyasına çift tıklayın (Windows)
Yöntem 2: start.sh dosyasını çalıştırın (Linux/Mac)
Yöntem 3: Terminal'de npm start komutunu çalıştırın
Tarayıcı: Uygulama otomatik olarak http://localhost:3000 adresinde açılacak

💡 Uygulama başladıktan sonra tarayıcınızda otomatik olarak açılacaktır.

🔧 Sorun yaşarsanız, terminal/komut satırında npm install komutunu çalıştırın.
